# Practical Guide Tab

## Goal

Add a public `实用指南` tab as a curated static information center for important notices, tutorials, and useful resources.

## Tasks

1. Add static guide content data in the frontend.
2. Build a compact guide page with category filters, priority entries, sidebar modules, and in-page detail reading.
3. Register `实用指南` in desktop navigation, mobile navigation, tab restoration, and footer channels.
4. Run the frontend build.
