# 首页内容位（手动内容 / 广告 / 其他信息）— 2026-11-11

状态：任务 1–4 全部已上线（2026-11-11）。全部未提交。

## 背景

首页重做后只有新闻、热门、招聘、公告。需要更多信息，尤其是管理员能手动添加的内容和广告位。

现状盘点（2026-11-11 本地接口）：

- 房产、二手、社区活动、社区帖子、招聘、公告的公开接口都在，但目前全部是 0 条。
- 公告功能已有完整链路：`announcements` 表 → `/api/announcements` + `/api/admin/announcements` →
  管理页“公告”标签（新建 / 编辑 / 置顶 / 上下线）。只有标题 + 正文，没有图片、链接、位置。
- 图片上传接口已有（`api.uploadMedia`）。

## 方案

不新建一套系统，把“公告”扩展成“首页内容位”：同一张表、同一个管理入口，多几个字段。

### 任务 1 — 后端：公告表加字段

`announcements` 表新增（`_migrate` 方式，旧数据不受影响）：

| 字段 | 取值 | 说明 |
|---|---|---|
| `kind` | `notice`（默认）/ `promo` | 平台公告 / 推广广告 |
| `placement` | `sidebar`（默认）/ `banner` / `feed` | 右侧栏 / 顶部横幅 / 新闻流中间 |
| `image_url` | 可空 | 配图 |
| `link_url` | 可空 | 点击跳转地址（仅允许 http/https） |
| `link_label` | 可空 | 按钮文字，如“了解详情” |
| `expires_at` | 可空 | 到期自动下线 |

`/api/announcements` 和管理接口接收并返回这些字段；公开接口过滤已过期的。

### 任务 2 — 管理页：编辑器加字段

“公告”标签改名“公告与推广”。编辑弹窗增加：类型、展示位置、图片上传、链接、按钮文字、到期日。
列表里显示类型和位置。

### 任务 3 — 首页：渲染内容位

- `banner`：顶部日期行下方一条横幅（最多 1 条，置顶优先）。
- `feed`：华人关注和葡萄牙新闻之间插入一张卡片（最多 2 条）。
- `sidebar`：右侧栏（现有公告位置；公告和推广都可以放）。
- `promo` 类型统一带“推广”小标记，和新闻区分开；外链 `target="_blank" rel="noopener sponsored"`。
- 没有内容的位置不占空间。

### 任务 4 — 首页：其他栏目自动出现

房产、二手、社区活动、社区帖子各取最新 3 条，有数据才显示对应区块，点击进入对应页面。
另加一个固定的“实用指南”入口区块（居留、税号、医保等常用指南的直达链接）。

## 需要确认

- 广告是站长手动录入（本方案），不接第三方广告联盟（如 Google AdSense）。
- 每个任务做完先给你看，再做下一个。
