## 目标

首页最上方加一块固定区域，放当前最重要的持续性话题，例如：

- 国家预算（OE）：今年的进展、主要内容、关键日期
- AIMA：当前情况、重要新闻、关键日期

和“公告与推广”的区别：公告是一条一条的短消息；这里是按“话题”组织的，每个话题长期存在、持续更新。

## 方案

### 每个话题包含

| 内容 | 来源 |
|---|---|
| 标题（如“2027 国家预算 OE”） | 管理员填写 |
| 当前状态（一句话，如“议会专项审议中”） | 管理员填写 |
| 要点（3–5 条短句） | 管理员填写 |
| 关键日期（日期 + 说明，多条） | 管理员填写；首页自动显示“还有 N 天 / 已过” |
| 相关新闻（最新 3 条） | 自动：按管理员设定的关键词从已抓取的新闻里匹配 |
| 详情链接（可选，指向实用指南或外部官方页面） | 管理员填写 |
| “更新于 X” | 自动 |

状态、要点、日期由管理员手动维护，保证准确；相关新闻自动更新，保证“实时”。

### 首页展示

- 位置：日期行下方、头条上方（横幅内容位在它上面或下面，见“需要确认”）。
- 桌面：话题并排成卡片（2 个话题各占一半；3 个以上横向排列）。
- 手机：话题标签切换，一次看一个，不把头条挤到很下面。
- 每张卡片：标题 + 状态 → 最近的 2–3 个关键日期 → 要点 → 相关新闻标题（点击打开文章）。
- 没有启用的话题时整块不显示。
