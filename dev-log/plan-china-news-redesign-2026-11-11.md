# 华人关注页面重做 — 2026-11-11

目标：让新闻内容本身更容易看清。

## 现状问题

- 页面上半部分被大块 hero（标题 + 头条 + 热门 + 日报）占满，新闻列表要滚一屏才出现。
- 主列表只收"正文 ≥ 180 字"的文章。现在批量翻译出来的正文普遍 100–200 字，绝大多数文章被归进右侧"简讯"，
  而简讯最多只显示 8 条 —— 实测 68 篇带华人标签的文章里只有约 11 篇能进主列表，其余大半看不到。
- 列表混入约 800 篇"社会/经济/国际"分类下还没翻译的葡语文章，中文内容被淹没。
- 列表先按标签数量排序，不是按时间，看不出哪条是新的。
- 卡片没有配图（68 篇里 49 篇有 `image_url`），摘要只显示两行。

## 方案（只改 `layout="china"`，葡萄牙新闻页不动）

1. 去掉 hero，改成一行标题 + 工具栏（搜索 / 日期 / 排序）。
2. 一个统一的信息流，不再分"精选 / 简讯"：
   - 按日期分组（今天 / 昨天 / X月X日），组内按时间倒序；按浏览排序时不分组。
   - 每条一行：华人话题标签、标题、最多 4 行中文内容、相关性说明、来源 · 时间 · 阅读数，右侧缩略图。
   - 第一条作为头条放大显示（大图）。
3. 默认只显示已翻译的文章；未翻译的折叠成一个"显示未翻译 N 条"开关。
4. 右侧栏（桌面端吸顶）：每日回顾 + 热门关注（5 条）。手机端：每日回顾在信息流上方，热门在下方。
5. 新组件 `components/news/NewsFeedRow.jsx`；`NewsTab.jsx` 的 china 分支重写。

## 验证

本地 Vite dev server，桌面宽度 + 手机宽度各看一遍，点开文章、切换排序 / 日期 / 搜索。
