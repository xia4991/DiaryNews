# 首页精简（去“AI 味”）— 2026-11-11

状态：待确认，尚未动代码。评估基于 `react-frontend/src/pages/HomePage.jsx`（588 行）的代码阅读。

## 问题

1. **自我解说的文案**：页面在解释自己，而不是给信息。例如“先看重点，再进入你今天最需要的页面”
   “今天建议：先看华人关注，再切到招聘或视频”“今天先从重点开始，剩下的内容交给平台慢慢补全”
   “让整个平台更完整”“排序会优先参考阅读量，并对近期新闻加权”。
2. **导航重复 5 遍**：顶部标签 + 侧边栏之外，首页里还有快捷入口 4 个、“现在可以做什么”、
   “按任务进入页面”、底部 Daily Flow 两个按钮。
3. **统计数字重复且无用**：6 张 StatCard，“新闻来源”出现两次，每张都带一句说明。
4. **装饰堆叠**：径向渐变背景、模糊光斑、5 处渐变卡片、28–40px 圆角、每张卡都有大阴影、
   每个标题上方都有彩色小标签、英文点缀（Portugal Chinese Hub / Daily Flow）、全大写加宽字距。
5. **真正的内容很少**：头条没有配图；华人关注只出 3 条；“葡萄牙新闻速览”和招聘条目不能点击。
6. **小错误**：
   - 头条取 `cnArticles[0]`（按标签数排序），可能是旧新闻或未翻译的葡语文章。
   - 文案提到“视频”，但没有视频页面。
   - 更新时间直接截取 UTC 字符串，不是本地时间。
   - “今日概览”里的“华人精选”和头条是同一篇。
   - 无公告时给管理员的提示里带反引号。
   - `tab === '首页' ? onLoginClick()` 是走不到的死代码。

## 方案

把首页做成一张“报纸头版”，只放内容：

1. 顶部一行：站名小标题 + 今天日期 + 新闻更新时间（本地时间）。去掉大标题、介绍段、快捷入口。
2. 左侧主栏：
   - 头条：最新一篇已翻译的华人相关新闻，带大图（复用 `NewsFeedRow lead`）。
   - 华人关注最新 5 条（复用 `NewsFeedRow`），末尾一个“全部华人关注”链接。
   - 葡萄牙新闻最新 6 条，紧凑标题列表，可点击打开。
3. 右侧栏：
   - 平台公告：有公告才显示；管理员无公告时只显示一行“发布公告”链接。
   - 热门新闻（保留今日/本周/全部切换），去掉说明文字。
   - 最新招聘 3 条，可点击进入招聘页。
4. 删除：6 张统计卡、“现在可以做什么”、“按任务进入页面”、Daily Flow 区块、“今日概览”卡、
   所有渐变/光斑背景和英文点缀。统计只在顶部一行里留一句“N 条华人相关 · N 个来源”。
5. 样式：统一用现有 `Card` 默认样式（白底、细边框、小圆角），不再单独写阴影和渐变。
