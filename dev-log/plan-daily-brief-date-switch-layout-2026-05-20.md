# Daily Brief Date Switch Layout

## Goal

Change the compact daily brief block into a hot-focus-like selector so the page shows one selected brief at a time instead of stacking all recent brief cards.

## Tasks

1. Add internal selected-date state to the compact `DailyBriefsSection`.
2. Render recent briefs as compact date buttons: today, yesterday, or date.
3. Show only the selected brief summary below the date selector.
4. Keep the existing click-through behavior to open the full daily brief detail modal.
5. Run the frontend build.
