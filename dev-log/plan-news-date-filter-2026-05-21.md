# News Date Filter

## Goal

Add a compact date filter to the Portugal news and Chinese focus pages. The filter should affect the main feed and sidebar brief cards, while leaving the top feature, hot news, and daily briefs unchanged.

## Tasks

1. Add date filter state and date helper functions in `NewsTab.jsx`.
2. Filter the shared feed before splitting into detailed articles and brief cards.
3. Add a compact `全部 / 今天 / 昨天 / date input` control beside the feed title.
4. Update empty states for date-filtered results.
5. Run the frontend build.
